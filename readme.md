## Deskripsi

My Store merupakan aplikasi web berbasis PHP menggunakan konsep MVC (Model View Controller). Aplikasi ini dibuat untuk membantu pengelolaan data produk dan kategori melalui dashboard admin.

## Fitur

- Login Admin
- Dashboard Admin
- Tambah Produk
- Edit Produk
- Hapus Produk
- Kelola Kategori Produk
- Koneksi Database MySQL

## Struktur Folder

```text
app/
config/
public/
views/
```

## Cara Menjalankan

1. Jalankan XAMPP dan aktifkan Apache serta MySQL.
2. Buat database dengan nama `mvc_mystore`.
3. Import file database yang tersedia.
4. Buka terminal pada folder project.
5. Jalankan perintah:

```bash
php -S localhost:8000 -t public
```

6. Buka browser dan akses:

```text
http://localhost:8000
```


## Penutup

Project ini dibuat sebagai ujian praktikum pemrograman web menggunakan PHP dan MySQL dengan konsep MVC.
